# 👋 About Me

Hi! I'm **Halil İbrahim Gerçek**, an independent developer based in **Germany**.

I enjoy taking an idea from:

> **“What if this worked?”**

to:

> **“Okay... it actually works.”**

My work sits at the intersection of **software, web development, automation, IoT and hardware experimentation**.

I learn by building, testing, breaking things, fixing them and documenting the useful parts.

### 🧠 My workflow

```text
       💭 IDEA
          │
          ▼
     🧪 PROTOTYPE
          │
          ▼
       🔨 BUILD
          │
          ▼
       🧪 TEST
          │
     ┌────┴────┐
     │         │
   ❌ FAIL    ✅ WORK
     │         │
```

# 🔓 Open-Source Philosophy

I believe open source works best when people can understand **how** something was made — not just download the finished result.

That's why I try to keep the development process visible.

### My principles

| Principle | Meaning |
|:---|:---|
| 🔓 **Open** | Share source code whenever possible |
| 🧪 **Experimental** | Test ideas instead of only talking about them |
| 🧠 **Learning** | Every project should teach something |
| 🛠️ **Practical** | Build things that actually do something |
| 📖 **Transparent** | Be honest about progress and limitations |
| 🤝 **Collaborative** | Make it possible for others to contribute |
| 🚀 **Iterative** | Improve continuously instead of waiting for perfection |
